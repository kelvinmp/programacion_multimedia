# Microsite Educativo sobre Música

Este proyecto es una página web educativa sobre teoría musical, creada para el curso de Programación Multimedia. 
La idea es que los estudiantes puedan aprender conceptos básicos de música de manera interactiva en un solo sitio, sin tener que navegar por múltiples páginas.

## Evaluación Nro. 1 – Estructura HTML, Navegación Simbólica e Hipermedios

Para construir el sitio, usé HTML5 con etiquetas que tienen sentido para organizar el contenido, como encabezados, barras de navegación y secciones. 
Esto hace que la página sea más clara tanto para los usuarios como para los buscadores. El diseño se trabajó con CSS, eligiendo colores que contrastan bien, 
una letra fácil de leer y un espacio adecuado entre los elementos. Todo esto busca que la experiencia de aprendizaje sea ordenada y agradable a la vista.

## Evaluación Nro. 2 – Análisis de Usabilidad y Feedback Interactivo

Pensando en el usuario, el sitio está hecho para que sea fácil de leer y entender. La letra es clara, el fondo no cansa la vista y cada sección está bien diferenciada. 
El menú permite moverse por todo el contenido sin que la página se recargue, lo que hace que la navegación sea fluida y natural.
Además, incluimos un formulario que valida lo que el usuario escribe en el momento. Si hay un error, aparece un mensaje inmediato para corregirlo;
si está bien, se confirma al instante. Esto se logró con JavaScript, usando una función que puede reutilizarse fácilmente.
Este detalle hace que la experiencia sea más interactiva y ayuda a que el aprendizaje sea más práctico y participativo.
